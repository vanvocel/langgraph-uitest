# LangGraph UI 自动化测试框架 — 落地计划

> 依据 `docs/设计方案.md` 的已确认设定。原则：**先跑通执行器，再固化契约，最后接 AI**。

---

## 总原则

```text
Phase 0 工程骨架
  → Phase 1 YAML 契约 + Tool 执行器（最优先）
  → Phase 2 通用登录 + 每需求 POM 目录
  → Phase 3 Toast 观察窗（业务核心）
  → Phase 4 LangGraph：NL → YAML
  → Phase 5 LangGraph：寻元素 → POM
  → Phase 6 打磨（造数 / 重绑 / CI …）
```

AI 依赖契约；契约未定就上 Agent，容易反复推翻。

---

## CLI 目标形态（分阶段实现）

```text
main.py init --req <id>       # Phase 0/2：建 runs/<id> 目录
main.py run --req <id>        # Phase 1 起：贯穿始终，优先实现
main.py compile --req <id>    # Phase 4：NL → YAML
main.py discover --req <id>   # Phase 5：寻元素写 POM
```

先实现 `run`，再补 `compile` / `discover`。

## Phase 3：Toast 观察窗【业务核心】

**工期**：约 2–3 天  

**目标**：正确处理「期望出现 toast」与「禁止错误 toast」；支持短 toast + 跳转组合断言。

### 任务

- [x] 全局 toast 监听（内存队列记录 `type` / `text` / `ts`）
- [x] 实现 `expect_toast` / `forbid: error` + `window_ms`
- [x] 与导航断言并行：先监听 → 再操作 → 观察窗内汇总判定
- [x] 默认 `forbid_toast_levels: [error]`，单步可覆盖（含「期望错误 toast」场景）
- [x] 失败日志附带「窗内捕获的全部 toast 列表」
- [x] 失败分类补充：`UI_ERROR_TOAST`
- [x] 与前端对齐 toast DOM / 级别识别规则（写入 `framework/toast/rules.yaml`，按 Element Plus `.el-message`）

### 完成标准

- 「期望成功 toast」可判定通过/失败  
- 「期望错误 toast」可判定通过/失败  
- 「跳转 + 禁 error toast」在 toast 已从 DOM 消失后仍能判对  

**状态：已完成（2026-09-21）**  
验证：`python -m pytest tests/test_toast_observe.py` → 5 passed（成功 toast、期望错误 toast、跳转+禁 error、禁止 error 失败并留下 toast 列表、缺期望 toast 失败）。  
规则：`framework/toast/rules.yaml`。单步 `forbid_toast_levels: []` 可覆盖默认禁 error。

## Phase 5：LangGraph — 寻元素 → POM

**工期**：约 3–5 天  

**目标**：AI 打开真实浏览器找元素；校验通过才写入**该需求 POM**。

### 任务

- [x] 节点链：从 YAML 收集元素 →（可选）bootstrap 登录 → 打开页 → **启发式候选 locator** → **校验** → 写 `runs/{id}/pom`
- [x] 门禁：可见、匹配数量、置信度阈值；失败不写该元素，写入 `bindings/discover.yaml` 标 `blocked`
- [x] 多策略候选 locator（role / text / label / Element Plus 表单项 / css）
- [x] CLI：`python main.py discover --req <id>`（`--force` 覆盖已有绑定）
- [x] 与 Runner 对接：discover 完成后可直接 `run`（DISCOVER-001 本地 fixture）
- [x] LLM 候选（DeepSeek）：启发式未绑中的元素，抽页面快照 → LLM 候选 → 校验后写入
- [x] CLI：`python main.py discover --req <id> --llm deepseek`（`--no-llm` 可关）
- [x] 绑定失败标记 `blocked` 写入 `bindings/discover.yaml`；未绑定元素执行期仍是 `BIND_ERROR`

### 完成标准

不手写 locator，也能对目标系统跑通 1 条需求用例并出 Allure。

**状态：DeepSeek 已接入（2026-10-07）**  
验证：`python main.py discover --req MG0473 --force --llm deepseek` → 绑定后 `run` **28 passed**。  
注意：筛选下拉/侧栏需排除 aside 的 xpath；纯 text 易点到侧栏同名菜单，POM 中这类元素用校验通过的 xpath。
